
# ColorLab V2

## Proyecto Integrador M1 - HENRY Full Stack

### Descripción
ColorLab V2 es una aplicación web para generar
paletas de colores aleatorios en formatos HSL y HEX.

### Funcionalidades previstas
- Generación de 6, 8 o 9 colores.
- Selección entre formatos HSL y HEX.
- Visualización de tarjetas dinámicas.
- Copiar códigos de colores.
- Bloqueo individual de colores.
- Interfaz adaptable a distintos dispositivos.

### Tecnologías
- HTML5
- CSS3
- JavaScript
- Git y GitHub

### Organización
- index.html: estructura HTML.
- css/styles.css: estilos visuales.
- js/script.js: lógica de la aplicación.
- documentacion/uso-ia.md: registro de IA.
